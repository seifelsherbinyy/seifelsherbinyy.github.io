Privacy policy

Last updated: 18 November 2026

NIZAM Al-Mulk is a private tool used only by its owner, in the owner's own Google account.

What it accesses

  • Google Drive: only files the app itself creates (drive.file scope).
  • Google Calendar: events, to create, read, update and delete the owner's events.
  • Google Tasks: the owner's task lists and tasks.

How data is used

Data is used only to perform the action the owner asks for. It is not sold, shared, used for advertising, or used to train models. Access tokens are stored only on the owner's private server with owner-only file permissions.

The app's use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

Removing access

The owner can revoke access at any time at myaccount.google.com/permissions.
